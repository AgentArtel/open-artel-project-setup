### Metric Definitions

- **Task completion rate**: Percentage of tasks reaching DONE status in the sprint
- **Review rejection rate**: Percentage of submissions rejected on first review
- **Boundary violations**: Number of times agents modified files outside their domain
- **Sprint velocity**: Number of tasks completed in the sprint period
- **Handoff latency**: Average time between submit commit and review/merge commit
- **Regression rate**: Percentage of merges that required post-merge fix tasks
- **Escalation rate**: Percentage of tasks escalated to Human or marked BLOCKED
- **Template coverage**: Percentage of task briefs following the standard template format
