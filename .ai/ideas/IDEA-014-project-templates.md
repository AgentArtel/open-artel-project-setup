## IDEA-014: Project templates for specific types

- **Category**: Templates
- **Origin**: TASK-002
- **Status**: raw

### The Idea

Create project templates for specific project types (not just generic starter kits). For example, templates for React + Supabase apps, Next.js SSR projects, Flutter mobile apps, etc.

### Why It Matters

Reduces setup time and ensures best practices for common project types. Templates can include pre-configured agent boundaries, tech stack conventions, and project-specific coordination patterns.

### Open Questions

- What project types should we support? (React + Supabase? Next.js? Flutter? Python backend?)
- How do templates differ from starter kits? (more specific? include evaluation criteria?)
- Where do templates live? (`setups/` directory? separate repo?)
- How do we version templates? (Git tags? semantic versioning?)
